# orchestrator

Orchestrator guideline, `orchestrate` skill, `explorer` and `fixer` subagents, and the `orchestrator-setup` skill (guided profile setup plus doctor).

Setup, usage and limitations are described in the [repository README](../../README.md).

Quick check: `bash skills/orchestrator-setup/scripts/doctor.sh`

If subagents run on the wrong model, see *Troubleshooting* in the repository README.
